emacs config 101

Managing to configure emacs out of the box on a fresh install is more than necessary for a better learning process. Instead of relying on heavy distributions like Doom or Spacemacs, building your own configuration from scratch forces you to understand the underlying Lisp machine.

"Emacs is not a text editor; it is an operating system lacking only a decent text editor." — An old UNIX joke, but technically accurate.

The Bare Minimum

Before we add fancy packages, we need to strip away the default GUI clutter. This keeps the interface clean, much like the bspwm philosophy on Arch Linux.

;; Disable GUI elements
(menu-bar-mode -1)
(tool-bar-mode -1)
(scroll-bar-mode -1)

;; Inhibit the startup screen
(setq inhibit-startup-message t)

Essential Packages

Once the UI is clean, we need to set up package management. Here are the core packages you will need:

  • use-package: A macro that makes configuration incredibly clean. Read the docs here.
  • ivy / counsel: For generic completion.
  • magit: The absolute best Git interface ever written.

Setup Instructions

If you are setting this up on a fresh Arch installation, follow these exact steps:

  1. Install the base package via pacman: sudo pacman -S emacs
  2. Create your initialization directory: mkdir -p ~/.config/emacs
  3. Touch your primary config file: touch ~/.config/emacs/init.el
  4. Restart the daemon.

By the end of this setup, you won't just have a text editor; you'll have a fully customized IDE built exactly for your workflow. Happy hacking, Atom.
